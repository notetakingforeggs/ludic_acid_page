Jonah’s Hermes Calendar

Jonah’s Hermes Calendar is a private personal integration connecting Jonah Russell’s self-hosted Hermes assistant to Google Calendar. It is not offered as a public application or service.

What it does

The integration reads calendar and scheduling information so Hermes can help Jonah review commitments and deadlines. It creates or updates calendar events only in response to Jonah’s requests.

Access and control

Access is limited to Google Calendar. Jonah can revoke it at any time through Google Account permissions or remove the credentials from the private Hermes instance.
